📝 Задача Z1: web_Hello_var_18

Тема: «Заказ билетов». Работа с маршрутизацией, шаблонами и формами без использования БД.

    Хранение данных: Текстовые файлы (.txt) и таблицы Excel (.xlsx) в папке tablica.

    Реализовано:

        Маршрутизация (path, re_path, параметры по умолчанию).

        Шаблоны (наследование от base.html, вывод списков, словарей, циклы).

        Формы (forms.py): валидация телефона и даты, выбор рейса, чекбоксы доп. услуг, сохранение заказа в Excel.

        Динамические страницы: расписание, фильтр по дням недели, информация о рейсе, список автобусов и заказов.

Инструкция по запуску находится внутри папки web_Hello_var_18 (через run.bat или вручную).
📝 Задача Z2.1: Папка Z2_1 (Одна таблица)

Тема: Управление автобусами.

    База данных: SQLite.

    Модель: Bus (Название, количество мест).

    Реализовано: Полный CRUD (Создание, Чтение, Редактирование, Удаление). Использован ручной разбор request.POST без forms.py.

Запуск:
bash

cd Z2_1
python manage.py makemigrations
python manage.py migrate
python manage.py runserver

Главная страница: http://127.0.0.1:8000/
📝 Задача Z2.2: Папка Z2_2 (Связь 1 ко многим)

Тема: Маршруты и рейсы.

    База данных: SQLite.

    Модели: Route (Маршрут) и Trip (Рейс). Один маршрут может иметь множество рейсов (ForeignKey).

    Реализовано: CRUD для обеих таблиц. При создании рейса используется выпадающий список (select) для выбора маршрута.

Запуск:
bash

cd Z2_2
python manage.py makemigrations
python manage.py migrate
python manage.py runserver

Главная страница: http://127.0.0.1:8000/
📝 Задача Z2.3: Папка Z2_3 (Связь многие ко многим)

Тема: Продажа билетов.

    База данных: SQLite.

    Модели: Passenger (Пассажир), Trip (Рейс) и промежуточная Ticket (Билет).

    Реализовано: Связь ManyToManyField через промежуточную таблицу. CRUD для всех трех сущностей. Можно продать билеты одному пассажиру на разные рейсы, и на один рейс — разным пассажирам.

Запуск:
bash

cd Z2_3
python manage.py makemigrations
python manage.py migrate
python manage.py runserver

Главная страница: http://127.0.0.1:8000/
📝 Задача Z2.4: Папка Z2_4 (Связь 1 к 1 + PostgreSQL)

Тема: Автобусы и их технические паспорта.

    База данных: PostgreSQL (драйвер psycopg).

    Модели: Bus (Автобус) и BusPassport (Техпаспорт). Связь OneToOneField.

    Реализовано: CRUD для автобусов и паспортов. В выпадающем списке при выдаче паспорта показываются только те автобусы, у которых еще нет паспорта.

⚠️ Настройка перед запуском:

    Убедитесь, что сервер PostgreSQL запущен.

    В DBeaver (или через консоль) создайте базу данных bus_db.

    В файле Z2_4/z2_4/settings.py укажите ваш пароль от PostgreSQL в блоке DATABASES.

Запуск:
bash

cd Z2_4
python manage.py makemigrations
python manage.py migrate
python manage.py runserver

Главная страница: http://127.0.0.1:8000/
